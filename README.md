# Superstore Data Visualization & Storytelling Dashboard

## Project Overview

This project is  focused on Data Visualization and Storytelling.

The goal was to analyze the Superstore dataset and create an interactive dashboard that communicates meaningful business insights through visualizations and KPIs.

The dashboard was built using Python, Streamlit, Plotly, and Pandas.

---

## Objective

- Analyze sales and profit data from the Superstore dataset.
- Create clear and interactive visualizations.
- Highlight important business insights.
- Demonstrate data storytelling techniques.

---

## Tools & Technologies Used

- Python
- Pandas
- Streamlit
- Plotly

---

## Dataset

Dataset Used: Sample Superstore Dataset

The dataset contains information about:
- Orders
- Sales
- Profit
- Customers
- Categories
- Regions
- Shipping Details

---

## Dashboard Features

### KPI Cards
- Total Sales
- Total Profit
- Total Orders

### Interactive Filters
- Region Filter
- Category Filter

### Visualizations

#### 1. Sales by Region
Displays total sales generated across different regions.

#### 2. Profit by Category
Shows profitability distribution among product categories.

#### 3. Profit by Customer Segment
Analyzes profit contribution from different customer segments.

### Business Insights Section
Automatically highlights:
- Highest sales region
- Most profitable category
- Growth opportunities

---

## Key Insights

### Regional Performance
The dashboard identifies which region contributes the highest sales and revenue.

### Category Analysis
Technology and Office Supplies categories generate significant profits compared to other categories.

### Customer Segment Analysis
Consumer customers contribute a major portion of overall profits.

### Business Opportunities
The analysis helps identify profitable areas for expansion and categories requiring improvement.
